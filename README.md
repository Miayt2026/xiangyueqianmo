# 乡约阡陌——AI赋能全国乡村农旅体验与助农服务平台

# 一、作品简介

「乡约阡陌」是一个AI赋能的乡村农旅体验+助农服务平台，覆盖全国县域场景，实现“游前AI规划→游中预约体验→游后溯源复购→全链AI赋能”的完整闭环。

三角色体系：

| 角色 | 演示账号 | 密码 | 主要能力 |
| --- | --- | --- | --- |
| 游客 | 游客小美 / 游客小凯 | 123456 | 浏览农旅/特产、AI出行规划、预约、下单、收藏、评价 |
| 商户 | 青山农家乐 / 赵大姐果园 | 123456 | 店铺/项目/房型/特产管理、AI文案、节气策划、评价分析 |
| 平台管理员 | 平台管理员 | 123456 | 商户入驻审核、全平台内容监管、用户账号管理、AI内容审核 |

七大AI应用场景：

1.AI出行规划——自然语言一键生成乡村出行方案

2.AI本地风物科普——进入农家乐详情自动生成知识卡片

3.AIGC多场景宣传文案——关键词生成3套风格文案

4.AI节气活动策划——按节气自动策划主题活动

5.AI评价智能分析——提取游客评价关键词并给经营建议

6.AI智能资源匹配——闲置农具/农房/用工/土地智能撮合

7.AI内容审核——管理端对商家文案进行合规检测

核心特色：

1.全程溯源：30款特产溯源码XYQM1001~1030，游客可输入溯源码查看“种植→采摘→检测→上架”全链路档案

2.农旅闭环：农家乐→项目/房型→在线预约→顺带加购特产→溯源复购

3.闲置共享：四类闲置资源发布+AI供需匹配，助力乡村降本增收

4.响应式设计：PC侧边栏+手机端汉堡菜单折叠，适配评委移动端评审

# 二、快速开始（本地运行源码）

## 环境要求

- Python 3.10 及以上（本机 3.14 验证通过）

- 依赖：flask、requests、qrcode、Pillow（pip install flask requests qrcode Pillow）

## 运行步骤

# 1. 进入项目目录

cd 乡约阡陌

# 2. 首次运行前初始化数据库（已存在 data.db 可跳过）

python init_db.py

# 3. 启动系统（自动打开浏览器 http://127.0.0.1:5001）

python app.py

端口说明：乡约阡陌使用 5001 端口

# 三、使用 exe 版

1. 解压 安装包-乡约阡陌-Windows.zip

2. 双击 乡约阡陌.exe

3. 程序自动初始化数据库并打开浏览器（http://127.0.0.1:5001）

- 首次启动若提示 Windows 安全警告，点击「更多信息 → 仍要运行」即可（未做代码签名导致）。

- 数据保存在 exe 同目录的 data.db，删除后重新启动会自动重建演示数据。

# 四、配置 AI 大模型（可选扩展，默认不调用外部大模型）

# 十、常见问题

Q：exe 双击后没有反应？

A：等待 1-2 秒会自动打开浏览器；若被杀软拦截，选择“仍要运行”。确认端口 5001 未被占用。

Q：exe 发队友能打开吗？

A：可以。PyInstaller 单文件 exe 自带 Python 运行时，解压后双击即用（Windows 10/11）。

Q：手机能打开吗？

A：手机不能直接运行 exe；部署到云服务器后，手机浏览器访问公网地址即可（页面为响应式设计）。

Q：如何换端口？

A：改 app.py 底部 port=5001 与 webbrowser.open 中的端口即可。
